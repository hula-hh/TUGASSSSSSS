# ABSENSIQU

Sistem absensi modern, responsive, dan siap disinkronkan ke Google Sheets.

## Fitur
- Dashboard statistik kehadiran
- Status Hadir, Terlambat, Izin, Sakit, Alpha
- Anti-duplikasi per siswa + tanggal
- Data siswa + ID untuk QR
- Rekap dan export CSV
- Dark mode
- Responsive mobile/desktop
- Google Sheets via Google Apps Script
- Mode demo saat URL Apps Script belum diatur

## Menjalankan
Buka index.html melalui static hosting atau Live Server.

## Google Sheets
Ikuti google-apps-script/SETUP.md lalu masukkan URL Web App pada menu Pengaturan.
