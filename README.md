# Sistem Absensi QR Code

Aplikasi web absensi siswa berbasis QR Code untuk tugas sekolah.

## Rencana fitur
- Dashboard
- Scanner QR Code melalui kamera browser
- Validasi QR siswa
- Pencegahan absensi ganda
- Penyimpanan data absensi
- Rekap kehadiran

## Struktur awal
- `index.html` — halaman utama
- `scanner.html` — halaman scanner
- `js/` — JavaScript
- `css/` — stylesheet
- `database/` — rancangan database
